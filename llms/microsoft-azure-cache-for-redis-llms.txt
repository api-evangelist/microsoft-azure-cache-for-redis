# Azure Cache for Redis

> Microsoft's managed in-memory data store built on the open-source Redis software. This file
> describes the MANAGEMENT (control-plane) API: the Microsoft.Cache/redis resource provider on
> Azure Resource Manager, which creates, scales, secures and deletes caches. The Redis data
> plane (GET/SET against the cache) is plain Redis, spoken with an ordinary Redis client and
> not described by any OpenAPI.
>
> Generated by API Evangelist from this repository on 2026-09-17. Microsoft does not publish an
> llms.txt for this product (portal.azure.com/llms.txt returns a 200 HTML shell, not a document).

## Status

- THE PRODUCT IS RETIRING. Enterprise and Enterprise Flash migrate to Azure Managed Redis on
  2027-03-31. Basic, Standard and Premium are turned off on 2028-09-30. New caches are already
  blocked for customers who had none before 2026-04-01.
- Current API version: 2024-11-01 (14 stable dated versions since 2015; none withdrawn).

## API

- Base URL: https://management.azure.com
- Every request must carry ?api-version=2024-11-01 — omitting it returns 400 MissingApiVersionParameter.
- Auth: OAuth 2.0 bearer token from Microsoft Entra ID (securityScheme `azure_auth`, scope
  `user_impersonation`). Discovery: https://login.microsoftonline.com/common/v2.0/.well-known/openid-configuration

## Rules an agent must follow

- Long-running: Redis_Create, Redis_Update, Redis_Delete, Redis_ExportData, Redis_ImportData,
  Redis_FlushCache and 7 others return 202. Poll the Azure-AsyncOperation header URL (fall back
  to Location), honour Retry-After, and stop at provisioningState Succeeded / Failed / Canceled.
- Idempotency is PARTIAL. PUT/DELETE by resource name are safe to retry. The five POST actions —
  export, import, flush, forceReboot, regenerateKey — are NOT, and there is no Idempotency-Key
  header. Do not blind-retry them.
- Reversibility: an export can be restored by an import (no stated window, and the import
  deletes existing cache data first). Scale up can be scaled back on Basic/Standard/Premium but
  NOT on Enterprise or Enterprise Flash. Delete, flush and key regeneration have no reversal.
- Pagination: follow `nextLink` in the body until it is absent. There is no page/limit parameter.
- Errors: {"error":{"code","message","target","details","additionalInfo"}} — the ARM/OData shape,
  not RFC 9457 problem+json. The actionable code is usually inside details[].
- Throttling: 429 with Retry-After. Read x-ms-ratelimit-remaining-subscription-reads / -writes /
  -deletes. Token bucket per subscription per region: reads 250 burst / 25 per second; writes and
  deletes 200 burst / 10 per second.
- Redis_ListKeys returns live secrets. Treat its response as a credential, never log it.

## MCP

Azure MCP Server (https://github.com/microsoft/mcp) is local-stdio only —
`npx -y @azure/mcp@latest server start`. It exposes two Redis tools, `redis_list` and
`redis_create`. There is NO remote MCP endpoint for Azure resource management; an agent cannot
reach this service over MCP without a human installing the server first.
Microsoft Learn MCP (https://learn.microsoft.com/api/mcp) is remote and anonymous but serves
documentation, not cache management.
